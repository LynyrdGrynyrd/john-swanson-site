Personal backup utility

Gitea Private Backups

An owner-operated tool for keeping encrypted copies of private Git repositories and forge configuration in the owner's Google Drive.

What it does

The tool encrypts a backup on an owner-controlled device before uploading it. It downloads the encrypted file again to check that the stored copy matches. Recovery is performed separately on an owner-controlled device.

Google Drive permission

The tool requests only drive.file: access to files created by, or explicitly selected for use with, this application. It creates a dedicated backup folder. The folder name itself is not an access restriction.

Personal use

This is a private utility maintained by John Swanson for his own account. It has no public signup, shared login or service for other users. These information pages do not expose the repositories, backups or administration interface.

Read the privacy policy and terms of use. For support, contact John Swanson.
